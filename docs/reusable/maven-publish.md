# 🚀 Maven Publish Workflow (removed)

> [!CAUTION]
> **Removed in `v2.0.0`.** `.github/workflows/maven-publish.yml` no longer exists in this repository.
> The last release that contains it is `v1.0.7`. Pins to `v1.0.7` or older keep working,
> but they receive no fixes.

## Replacement

- Releases: [maven-release](../../actions/maven-release/README.md)
  (or [maven-monorepo-release](../../actions/maven-monorepo-release/README.md) for monorepos).
- Snapshots: [maven-snapshot-deploy](../../actions/maven-snapshot-deploy/README.md).

See the [actions and workflows catalog](../actions-workflows-catalog.md) for the current inventory.
